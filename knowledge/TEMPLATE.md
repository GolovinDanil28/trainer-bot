# Шаблон заметки

Копируй этот файл в нужный раздел, переименуй по-slug, заполни. Не заводи
пустые заглушки — удаляй шаблон, если заметка не нужна.

```markdown
---
title: <заголовок — утверждение, а не тема>
tags: [agents, opencode]
created: <YYYY-MM-DD>
source: <ссылка, если взято извне; иначе — "своё">
applied_in: <файл:строка или openspec/changes/<id>>
---

# <заголовок>

**Вопрос, на который отвечает эта заметка:**
<один вопрос>

**Ответ:**
<2–6 предложений или список. Только суть, без воды>

## Пример

<конкретный пример из своего проекта, с путём к файлу>

## Почему это важно / когда пригодится

<1–3 предложения: в какой ситуации ты это вспомнишь>

## Связанное

- [[другая-заметка]]
```

## Правила заполнения

- `title` — **утверждение**, а не тема. «`permission.hook` вызывается после
  правил агента» лучше, чем «Permissions».
- `tags` — из 2–4 слов, маленькими буквами. Теги нужны для оглавления.
- `applied_in` — обязательно. Нет применения → нет заметки.
- Если заметка противоречит другой — укажи это явно в «Связанное».
