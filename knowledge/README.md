# База знаний трека «AI Engineering»

Здесь живут заметки по теме №4 из `ПРОЕКТЫ.md`. Это не документация продукта —
это **твои заметки** по тому, как устроена работа с ИИ.

## Правила

1. Заметка = **один** факт или одна идея, а не глава учебника.
2. Своими словами. Если пересказ чужого текста — так и напиши, откуда.
3. Каждая заметка начинается с **вопроса**, на который она отвечает. Это важно:
   заметка без вопроса не нужна.
4. Обязательно поле «где применял» — ссылка на реальный кусок кода или спеы.
   Знание, которое не применено, через неделю выветривается.

## Когда RAG вообще нужен

Честный ответ: **сейчас — не нужен.**

Корпус из 10–30 заметок ищется `grep`-ом за миллисекунды. Эмбеддинговый
индекс на таком объёме — это:
- лишние зависимости (векторная БД, модель эмбеддингов);
- лишняя операционка (пересборка индекса, деградация качества);
- иллюзия умности: «у нас RAG» вместо «я умею искать».

RAG становится оправдан, когда выполняются **оба** условия:

1. корпус больше ~200 страниц (~500 заметок) **или** в нём много
   пересекающихся тем, где keyword-поиск систематически промахивается;
2. есть **реальный вопрос**, который grep не решает — например: «найди все
   места, где мы принимали решения про идемпотентность».

До этого — `grep` + `knowledge/INDEX.md`. Это и есть гибридный поиск: сначала
дешёвый и точный, потом (если есть) семантический.

Проверка «нужен ли RAG» — вопрос из `knowledge/rag/when-not-to-use.md`.

## Как пользоваться

- Агент `researcher` ищет здесь: сначала `grep`, потом индекс (если есть),
  потом внешние источники.
- Пополняет базу — по шаблону `knowledge/TEMPLATE.md`.
- Оглавление — `knowledge/INDEX.md`. Он тоже обновляется.

## Структура

```
knowledge/
├── INDEX.md          # оглавление: заголовок, теги, одна строка сути
├── TEMPLATE.md       # шаблон заметки
├── agents/           # агенты, harness, оркестрация
├── spec/             # спецификация как контракт, OpenSpec
├── rag/              # память, поиск, RAG
├── tools/            # MCP, локальные модели, инструменты
└── practice/         # методика обучения, ретро
```
