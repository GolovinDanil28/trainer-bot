# Журнал обучения

Пишется через `/retro`. Формат — короткие блоки. Это **единственное** место,
где пишется от первого лица пользователя: если формулировка не звучит как твоя
речь — перепиши.

Зачем: через 3 месяца ты забудешь, как принимал решения. Этот файл — память о
твоём росте, а не отчёт об агенте.

---

## Шаблон записи

```markdown
### <дата> — <тема>

**Делали:** 2–4 пункта, что фактически сделали.

**Решения:**

| Решение | Альтернативы | Почему выбрали |
|---|---|---|
| | | |

**Что понял:** своими словами, 1–3 пункта. Не пересказ документации, а
формулировка, которую ты можешь использовать сам.

**Что осталось непонятным:** 1–2 пункта — это темы для следующего `/teach`.

**Артефакты:** какие спеки, файлы, заметки созданы.
```
