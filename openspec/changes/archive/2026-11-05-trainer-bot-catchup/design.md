# Design: trainer-bot-catchup

### D1. Догон — часть того же прохода, а не отдельный job

Тик и так знает зоны и владельцев. Отдельный job пришлось бы синхронизировать
с основным, чтобы не отправить дважды; общий проход и `claim_reminder` решают
это базой.

### D2. Окно по умолчанию 2 часа

«Пропустил 20 минут» — ещё напоминание; «пропустил 5 часов» — уже нет.
Значение настраивается; 0 выключает догон для тех, кто не хочет поздних
сообщений.

### D3. Прошлые сутки, а не только сегодня

Окно может пересечь полночь: тренировка в 23:30, бот поднялся в 00:20.
Поэтому проверяются сегодняшняя и вчерашняя локальные даты, а не только
«сегодня».

### D4. Вне окна — молчание

Создавать «пропущенное» напоминание задним числом нельзя: журнал заполнится
строками, которых владелец не видел. Вне окна момент просто не существует —
как сейчас.

## Risks

- **[Догон после долгого простоя]** → окно ограничивает: через сутки не
  напомнит.
- **[Дубль с обычным окном]** → `claim_reminder` уникален; кандидаты
  пересекаются, но займётся только один.
- **[Позднее сообщение в неудобный час]** → владелец сам выбирает окно;
  0 отключает.
