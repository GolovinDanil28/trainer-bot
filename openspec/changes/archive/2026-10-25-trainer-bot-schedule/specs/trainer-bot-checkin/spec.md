# Spec Delta

## Purpose

Журнал отметок: единственное место, где появляются факты «сделал / пропустил».
На эти данные опирается следующий change — корректировка плана по самочувствию.

## ADDED Requirements

### Requirement: R-11 Отметка по inline-кнопке
Система SHALL записывать отметку `done` или `skipped` по нажатию кнопки под
напоминанием и привязывать её к конкретному напоминанию.

#### Scenario: Нажата кнопка «сделал»
- **WHEN** пользователь нажимает «сделал» под напоминанием
- **THEN** в журнале появляется запись `done` для этой тренировки и этого дня

#### Scenario: Нажата кнопка «пропустил»
- **WHEN** пользователь нажимает «пропустил»
- **THEN** в журнале появляется запись `skipped` с датой напоминания

#### Scenario: Посторонний пользователь нажимает кнопку
- **WHEN** кнопку нажимает не владелец
- **THEN** отметка не создаётся, история не меняется

### Requirement: R-12 Повторное нажатие не перезаписывает историю
Система SHALL сохранять первую отметку по напоминанию и на повторное нажатие
отвечать, что отметка уже сделана, без изменения журнала.

#### Scenario: Двойной тап
- **WHEN** пользователь дважды нажимает «сделал» под одним напоминанием
- **THEN** в журнале остаётся одна запись `done`, а бот отвечает «уже отмечено»

#### Scenario: Попытка передумать
- **WHEN** после `done` пользователь нажимает «пропустил»
- **THEN** запись остаётся `done`, бот сообщает, что изменить отметку нельзя

### Requirement: R-13 Журнал выполнения доступен пользователю
Система SHALL показывать по команде `/history` последние отметки в таймзоне
пользователя в виде «дата — тип тренировки — результат», включая строки «без
ответа».

#### Scenario: Пять последних отметок
- **WHEN** пользователь отправляет `/history`
- **THEN** бот возвращает до пяти последних записей: дата, тип тренировки,
  результат `done` / `skipped` / «без ответа»

#### Scenario: История пуста
- **WHEN** пользователь отправляет `/history`, не имея ни одной отметки
- **THEN** бот отвечает, что история пока пуста, и подсказывает, как появится
  первая запись
