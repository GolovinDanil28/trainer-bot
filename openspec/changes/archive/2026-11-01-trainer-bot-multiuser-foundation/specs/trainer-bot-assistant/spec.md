# Spec Delta — trainer-bot-assistant

## MODIFIED Requirements

### Requirement: R-18 Свободный текст принимается только от владельца
Система SHALL обрабатывать текстовые сообщения только от зарегистрированного
пользователя; для остальных не вызывать модель и не раскрывать состояние
расписания. Контекст, который видит модель, SHALL содержать только тренировки
этого пользователя.

#### Scenario: Посторонний пользователь
- **WHEN** пользователь с чужим Telegram id отправляет «покажи расписание»
- **THEN** бот отвечает нейтральным отказом, модель не вызывается, состояние не
  меняется

#### Scenario: Владелец
- **WHEN** зарегистрированный пользователь отправляет «покажи расписание»
- **THEN** сообщение обрабатывается как текстовый ввод и возвращает его
  расписание

#### Scenario: Чужое не попадает в контекст модели
- **WHEN** два пользователя зарегистрированы и у каждого есть тренировки
- **THEN** снапшот расписания в промпте содержит только тренировки автора
  сообщения
