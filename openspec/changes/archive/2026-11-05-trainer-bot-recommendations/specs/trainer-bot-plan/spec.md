# Spec Delta — trainer-bot-plan

## ADDED Requirements

### Requirement: R-49 Рекомендация на следующую неделю
Система SHALL по команде `/advice` показывать рекомендацию: число тренировок и
типичную длительность. Рекомендация SHALL строиться по последним четырём
завершённым неделям: если пропущено не меньше трети запланированного — на одну
тренировку меньше текущего расписания. Если недель с данными меньше двух,
совет SHALL строиться по текущему расписанию с пометкой о нехватке данных.
Расписание SHALL NOT меняться.

#### Scenario: Пропусков больше трети
- **WHEN** за 4 недели пропущено 5 из 12 элементов плана, сейчас 3 тренировки
- **THEN** рекомендация — 2 тренировки, типичная длительность как сейчас

#### Scenario: Пропусков мало
- **WHEN** пропущено 1 из 12, сейчас 3 тренировки
- **THEN** рекомендация — 3 тренировки

#### Scenario: Мало данных
- **WHEN** снимков меньше чем за 2 недели
- **THEN** рекомендация — по текущему расписанию, с пометкой «данных мало»

#### Scenario: Расписание пусто
- **WHEN** активных тренировок нет
- **THEN** рекомендация — начать с одной тренировки на 30 минут

#### Scenario: Расписание не меняется
- **WHEN** рекомендация построена
- **THEN** число активных тренировок и их время в базе не изменились

#### Scenario: Только свои данные
- **WHEN** у двух пользователей разные истории и расписания
- **THEN** каждый получает рекомендацию по своим данным

#### Scenario: Работа без модели
- **WHEN** владелец отправляет `/advice` при выключенной Ollama
- **THEN** ответ приходит без вызова модели
