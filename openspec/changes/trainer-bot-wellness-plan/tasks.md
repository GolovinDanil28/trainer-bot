# Tasks

Порядок блоков — порядок выполнимости: каждый следующий опирается на предыдущий.
Внутри блока пункты независимы. Каждый пункт закрывается тестом.

Продуктовые решения утверждены 27.10.2026: правила плана (3.1), честный текст
отдыха при живом напоминании (3.3) и вечерний вопрос в паре с командой
`/wellness` (1.2, 4.4, 5.2).
