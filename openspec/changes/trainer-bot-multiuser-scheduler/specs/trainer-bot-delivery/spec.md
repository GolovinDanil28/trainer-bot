# Spec Delta — trainer-bot-delivery

## MODIFIED Requirements

### Requirement: R-06 Наступившее напоминание отправляется один раз
Система SHALL отправлять напоминание не более одного раза на пару
`(тренировка, момент напоминания)`; повторные проверки планировщика и перезапуск
бота не создают второго сообщения. Напоминание SHALL уходить владельцу
тренировки — в его чат и по его таймзоне.

#### Scenario: Тик планировщика совпал с моментом напоминания
- **WHEN** наступило время напоминания для тренировки
- **THEN** владелец тренировки получает одно сообщение, факт отправки записан

#### Scenario: Перезапуск бота в ту же минуту
- **WHEN** бот перезапускается сразу после отправки и снова проверяет наступившие
  напоминания
- **THEN** повторное сообщение не отправляется, а в БД остаётся одна запись
  напоминания

#### Scenario: Две проверки одновременно
- **WHEN** два прохода планировщика пытаются обработать один и тот же момент
- **THEN** отправка происходит только для того прохода, который первым вставил
  запись на уникальный ключ, второй проход молча пропускает момент

#### Scenario: Два пользователя
- **WHEN** у двух пользователей наступили напоминания
- **THEN** каждый получает своё, и ни одно не уходит другому

#### Scenario: Чужая тренировка
- **WHEN** проход одного пользователя видит тренировку другого
- **THEN** она не занимается и не отправляется
