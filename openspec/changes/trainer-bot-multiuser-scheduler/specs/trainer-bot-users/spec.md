# Spec Delta — trainer-bot-users

## ADDED Requirements

### Requirement: R-44 Регистрация по инвайт-коду
Система SHALL регистрировать пользователя командой `/start <код>`, если код
совпадает с `INVITE_CODE`. При регистрации SHALL копироваться таймзона и времена
вопроса и разбора из настроек. Код SHALL быть многоразовым; незаданный или
пустой код SHALL отключать регистрацию. Неверный код SHALL NOT создавать
пользователя. Повторная регистрация SHALL быть идемпотентной.

#### Scenario: Верный код
- **WHEN** незарегистрированный пользователь отправляет `/start <верный код>`
- **THEN** создаётся учётная запись с настройками по умолчанию и приходит карточка

#### Scenario: Неверный код
- **WHEN** пользователь отправляет `/start <неверный код>`
- **THEN** учётная запись не создаётся, приходит подсказка про код

#### Scenario: Код не задан
- **WHEN** `INVITE_CODE` пуст, а незарегистрированный пишет `/start <код>`
- **THEN** регистрация недоступна, учётная запись не создаётся

#### Scenario: Повторная регистрация
- **WHEN** зарегистрированный пользователь снова отправляет `/start <код>`
- **THEN** второй учётной записи нет; приходит та же карточка

#### Scenario: Настройки из конфига
- **WHEN** пользователь регистрируется при `TZ=Asia/Yekaterinburg`
- **THEN** его таймзона и времена вопроса/разбора равны значениям из настроек

## MODIFIED Requirements

### Requirement: R-41 Учётная запись пользователя
Система SHALL хранить пользователя с telegram id, таймзоной, временем вечернего
вопроса, временем недельного разбора и признаком активности. Владелец из
`OWNER_ID` SHALL создаваться автоматически и идемпотентно при старте. Пользователь
без учётной записи SHALL получать отказ, кроме команды регистрации (R-44).
Пользователь с `is_active=false` SHALL NOT получать напоминаний, вопросов и
разборов, а его команды SHALL получать отказ.

#### Scenario: Владелец создаётся при старте
- **WHEN** бот запускается с `OWNER_ID`, которого ещё нет в базе
- **THEN** создаётся пользователь с таймзоной и временами из настроек

#### Scenario: Повторный старт не дублирует
- **WHEN** бот запускается второй раз с тем же `OWNER_ID`
- **THEN** у пользователя по-прежнему одна строка, настройки не сбрасываются

#### Scenario: Незарегистрированный получает отказ
- **WHEN** сообщение приходит от telegram id, которого нет в базе, и это
  не команда регистрации
- **THEN** бот отвечает отказом и не показывает данные бота

#### Scenario: Отключённый пользователь
- **WHEN** у пользователя `is_active=false`
- **THEN** команды получают отказ, а тики не отправляют ему напоминания,
  вопрос и разбор
