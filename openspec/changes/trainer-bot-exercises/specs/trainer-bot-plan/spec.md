# Spec Delta — trainer-bot-plan

## ADDED Requirements

### Requirement: R-50 Упражнения в рекомендации
Система SHALL в `/advice` показывать упражнения по одному блоку на семейство
текущих тренировок; неизвестный тип блока не получает. Программа — 8 недель по
2 недели на фазу от первой активной тренировки семейства в зоне пользователя;
с 9-й недели цикл начинается заново с пометкой. Текст SHALL содержать пометку,
что это общая подсказка, а не медицинская рекомендация.

#### Scenario: Первые две недели
- **WHEN** первая силовая создана 10 дней назад
- **THEN** блок силовой показывает первую фазу и «неделя 2 из 8»

#### Scenario: Пятая неделя
- **WHEN** с первой тренировки семейства прошло 5 недель
- **THEN** показывается третья фаза

#### Scenario: Восьмая неделя
- **WHEN** с первой тренировки семейства прошло 55 дней
- **THEN** показывается четвёртая фаза, цикл ещё не завершён

#### Scenario: Цикл завершён
- **WHEN** с первой тренировки семейства прошло 56 дней (9-я неделя)
- **THEN** показывается первая фаза и пометка «цикл завершён, начинаем заново»

#### Scenario: Два семейства
- **WHEN** в расписании есть силовая и бег
- **THEN** в совете два блока — силовой и кардио, по одному

#### Scenario: Неизвестный тип
- **WHEN** тип тренировки не узнаётся как семейство
- **THEN** блока для него нет, остальной совет не меняется

#### Scenario: Пустое расписание
- **WHEN** тренировок нет
- **THEN** блоков упражнений нет

#### Scenario: Пометка о риске
- **WHEN** блоки показаны
- **THEN** в тексте есть «не медицинская рекомендация»
