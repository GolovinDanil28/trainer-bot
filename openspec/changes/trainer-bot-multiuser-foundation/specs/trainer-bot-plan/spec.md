# Spec Delta — trainer-bot-plan

## MODIFIED Requirements

### Requirement: R-36 Снимок выданного плана
Система SHALL сохранять снимок плана в момент, когда план показан пользователю:
дату плана, оценку самочувствия, признак отдыха и элементы (тип, время,
длительность, `workout_id`). Снимок SHALL быть один на пару «пользователь +
дата»: повторный показ заменяет его целиком. Снимок SHALL NOT записываться, пока
план не показан.

#### Scenario: План показан вечером
- **WHEN** пользователь отвечает на вечерний вопрос о самочувствии и получает план
- **THEN** сохраняется его снимок на дату плана с оценкой и элементами

#### Scenario: Повторный показ заменяет
- **WHEN** план на ту же дату показан этому же пользователю второй раз
  (например, после `/plan`)
- **THEN** в базе остаётся один его снимок этой даты, элементы — последнего
  показа; снимок другого пользователя не тронут

#### Scenario: Снимок при отдыхе
- **WHEN** оценка 1–2 и план советует отдых
- **THEN** снимок сохраняется с признаком отдыха и пустым списком элементов

#### Scenario: Ошибка или отказ в плане
- **WHEN** план не показан (нет оценки, текст ошибки)
- **THEN** новый снимок не появляется

#### Scenario: Два пользователя — два снимка
- **WHEN** два пользователя получают план на одну дату
- **THEN** в базе два снимка, по одному на пользователя
