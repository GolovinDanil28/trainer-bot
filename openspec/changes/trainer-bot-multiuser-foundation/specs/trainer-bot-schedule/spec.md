# Spec Delta — trainer-bot-schedule

## MODIFIED Requirements

### Requirement: R-05 Команды принимаются только от владельца
Система SHALL игнорировать команды расписания и журнала (`/new`, `/list`, `/off`,
`/history`) от любого Telegram-пользователя, которого нет в базе среди
зарегистрированных, и не раскрывать в ответе состояние расписания. Владелец из
конфигурации SHALL быть зарегистрирован при первом запуске и видеть только свои
данные.

#### Scenario: Посторонний пользователь
- **WHEN** пользователь с чужим Telegram id отправляет `/list`
- **THEN** бот отвечает нейтральным отказом и не возвращает названия тренировок

#### Scenario: Владелец
- **WHEN** зарегистрированный владелец отправляет `/list`
- **THEN** бот возвращает полный список его тренировок

#### Scenario: Второй зарегистрированный пользователь
- **WHEN** второй пользователь отправляет `/list`
- **THEN** бот возвращает его тренировки и ни одной чужой
