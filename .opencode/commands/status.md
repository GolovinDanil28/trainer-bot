Собери статус хаба. Ничего не меняй, только отчитайся.

Собери данные:

1. **Активные спеки.** Найди `openspec/changes/*/` (без `archive/`). Для каждой:
   id, заголовок из `proposal.md`, сколько пунктов `- [ ]` / `- [x]` в
   `tasks.md`.
2. **Незакрытые спеки.** Те, где есть `- [ ]` — самые важные.
3. **Журнал обучения.** Последние 3–5 записей из `learning/LOG.md` — заголовки
   и по одной строке «что понял».
4. **База знаний.** Сколько заметок в `knowledge/`, сколько в `knowledge/INDEX.md`,
   есть ли индекс (`knowledge/index/`).
5. **Хаб-конфигурация.** Сколько агентов в `.opencode/agents/`, команд в
   `.opencode/commands/`, скиллов в `.opencode/skills/`, работает ли плагин
   `.opencode/plugins/guardrails.ts` (по логу `~/.local/share/opencode/log/opencode.log`
   поищи `guardrails`).
6. **Токены.** Из `opencode api get /session` или из лога — расход текущей
   сессии, если доступно. Не выдумывай, если недоступно — напиши «н/д».

Выведи компактно:

```
## Статус хаба

### Спеки
| change | готово | статус |
|---|---|---|
| trainer-bot-mvp | 7/12 | в работе |

### Следующий шаг
<одна строка: какой пункт tasks.md делать следующим>

### Журнал обучения
...

### Хаб
агенты: 5 · команды: 4 · скиллы: 3 · плагин: работает
```

В конце — одна строка «Рекомендация»: что делать дальше, исходя из статуса.
