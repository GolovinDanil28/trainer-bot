Создай спеку изменения по описанию: **$ARGUMENTS**

Действуй по инструкции агента `planner`:

1. Изучи контекст: `AGENTS.md`, `ПРОЕКТЫ.md`, существующие спеки в
   `openspec/specs/`, релевантный код.
2. Если намерение допускает несколько трактовок — задай уточняющие вопросы
   через `question` ДО написания спекы.
3. Создай `openspec/changes/<change-id>/` с файлами `proposal.md`, `design.md`,
   `tasks.md` и `specs/<capability>/spec.md`.
4. Требования — в формате OpenSpec (`SHALL` + сценарии `WHEN`/`THEN`).
5. В `tasks.md` каждый пункт ссылается на требование.

В конце верни: id изменения, путь к спеке, список требований по одному
предложению, открытые вопросы, и явную просьбу **подтвердить спеку** —
до подтверждения код не пишется.
